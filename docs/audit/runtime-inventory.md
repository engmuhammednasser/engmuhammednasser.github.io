## Before-state decisions to carry into implementation

1. Preserve the ambient visual language and homepage hero fallback, but make effects optional and capability-gated.
2. Remove the splash cursor unless a later browser review demonstrates a clear identity benefit that justifies a second canvas loop.
3. Remove the document-wide `MutationObserver` and runtime role inference. The static export already has deterministic markup; future source/build work should emit visual classes at render/post-processing time.
4. Centralize reduced-motion, pointer, hover, viewport, visibility, and WebGL decisions so individual effects cannot drift into different capability policies.
5. Treat hidden/offscreen state as a lifecycle transition: stop or cancel animation scheduling and resume only when eligible.
6. Keep all effects outside content, navigation, links, and layout correctness. Context/shader failure must fall back cleanly and remain observable through a warning rather than silently changing content behavior.

## Unknowns

- Browser-level Core Web Vitals and actual GPU cost are not measurable in this checkout because no supported Chromium/Playwright/Puppeteer/Lighthouse harness is available.
- The exact source component boundaries are unavailable; deterministic class ownership can be improved in the static post-processing layer, but a durable source-level fix waits for source recovery.
- WebGL availability by target device is not inferable from static files. The implementation must feature-detect context creation at runtime and record the unsupported path in validation documentation rather than assuming support.
